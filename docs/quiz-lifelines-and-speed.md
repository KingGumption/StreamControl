# Quiz lifelines, speed rewards and arcade audio

- The displayed answer countdown is followed by two seconds of grace. The question remains visible, with “Accepting final answers…” at zero. Results stay hidden until grace ends. Server receipt time determines acceptance; the exact closing boundary rejects a message. Host “Close answers & reveal” remains an explicit early-close override.
- Send a standalone `pass` (case-insensitive) instead of an answer. The first valid answer or successful pass locks. Passing costs the free pass first, then the saved bonus, preserves survival and adds no correct-answer or speed points. No available pass means the command is ignored and the player can still answer.
- Each quiz gives one free pass. One additional bonus can be saved across quizzes. Spending a saved bonus is immediately durable; stopping/restarting a game does not refund it. Unspent saved bonuses remain. Banks use platform and stable user ID, not display name; accounts on different platforms are separate.
- On natural completion the survival winner and speed champion each earn a bonus for a future game, capped at one saved. Winning both still saves only one. Stopped games and preview tests do not grant real rewards. Existing solo/last-player victory rules are unchanged; historical wins do not create retroactive passes.
- Each question awards 3/2/1 points to the first three correct submissions, ordered by server receipt sequence. Wrong answers and passes receive none. The podium appears only at reveal. The speed champion is selected from every participant, including eliminated players: highest points, then most first places, then lowest combined response time on podium answers, then earliest lobby join. A game with no correct answers has no speed champion. Network/platform delays can affect ranking.
- Pass balances appear on the existing player cards during lobby/questions. The compact overlay retains its eight-card limit. Sudden death has a visual announcement and an arcade cue. The final outcome recognises the speed champion separately from the survival winner.
- Original locally generated arcade sounds play only on `/quiz`, not admin or preview pages: question opening, last-three-second ticks, reveal, podium, sudden death and outcome. Controls on the quiz admin page save mute/volume for all overlay clients, default 35%. Refresh the OBS browser source after deployment and ensure that source's audio is audible in OBS. Ordinary browsers may require interaction to allow audio. Repeated state updates do not replay cues; opening an overlay on completed results does not replay the outcome.

Two additive SQLite tables store capped bonus balances and idempotent game awards. Existing history and analytics remain. The isolated playable preview includes a Pass button and never touches the real pass bank.
