Privacy Policy

Last updated 1 October 2026

This policy explains how KingGumption’s StreamEngagement service handles information from the site, stream interactions and connected creator accounts.

Information the service handles

  • Stream interactions: platform names and IDs, display names, viewer count snapshots, song requests, game activity, roles, timestamps and Polaroid captures or related events where those features are used.
  • Creator analytics: post links, titles, dates, durations, public performance counts and any additional metrics, notes, references or experiments imported into Content Coach.
  • Account connections: when a creator authorises TikTok, the service obtains a TikTok account identifier, display name, access and refresh tokens, and the recent public video metadata and counts allowed by the approved scopes. Other platform connections may use their own authorisation details.
  • Site access: login credentials, an authenticated session cookie, security/audit events and routine server logs needed to operate the site.

Why it is used

StreamEngagement uses this information to run stream tools and overlays, identify activity across sessions, show analytics, compare a creator’s published posts, maintain account connections, and protect restricted pages. Content Coach keeps published-content analysis separate from live-stream strategy. Its daily process stores post metadata, cover links, metric snapshots and recommendations. It may also show links and public figures for related YouTube videos.

Who can see it

The control room and detailed analytics are restricted to authorised accounts. Some overlays, event streams and Polaroid image URLs are public so broadcast software and viewers can load them. A configured Polaroid flow may also send an image or link to Discord or Twitch chat. Connected platforms receive requests needed for the feature you use. When AI analysis is configured, selected post text, available metrics, public cover links and own-post comparison figures are sent to OpenAI to generate Content Coach recommendations. Competitor examples are excluded from AI analysis unless a separate approval setting is enabled. The app is hosted on Render, which processes stored data and service logs for operation of the site. Data is not sold.

Storage, security and retention

The service keeps operational data in its hosted database and storage. TikTok access and refresh tokens are encrypted before storage. Admin sessions use signed, HTTP-only cookies; production connections use HTTPS. Stored records may remain until the operator removes them or the service is retired; there is no automatic deletion schedule for all analytics or imported observations.

Your choices and requests

You can decline a platform connection. An authorised user can export Content Coach data, remove individual observations, and disconnect TikTok; disconnecting revokes its token but does not automatically remove previously imported observations. For access, correction or deletion requests involving information held by StreamEngagement, contact the operator through the KingGumption GitHub profile. Do not include private account details in a public GitHub issue; ask for a private contact method first. You can also manage a platform’s permissions in that platform’s account settings.

Changes and contact

This page may be updated as features or integrations change. The current version and date will be posted here. Questions about this policy can be directed through the KingGumption GitHub profile.
